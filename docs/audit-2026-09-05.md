# Audit pra-deploy — 5 September 2026

Audit ini melanjutkan perubahan lokal yang sudah ada. Pengujian integrasi menggunakan database sementara `/tmp/pib-audit-final/test.sqlite`, bukan database kerja.

## Perbaikan

- Rekap, laporan, dan progress dashboard menghitung materi sesuai tahun ajaran kelas.
- Ringkasan ekspor memakai bobot materi, membedakan siswa berdasarkan ID, dan memisahkan kelas bernama sama antarperiode.
- Nilai kosong dilabeli belum dinilai pada detail laporan; nilai 0 tetap dihitung sebagai hasil penilaian.
- Sinkronisasi mendeteksi perubahan sejak nilai dibuka, termasuk saat dua editor pertama kali menilai siswa yang sama. Versi nilai berbeda untuk penyimpanan cepat, dan penulisan nilai serta pencatatan sinkronisasi dilakukan dalam satu transaksi.
- Pengiriman ulang operasi yang sudah berhasil mengembalikan keadaan server saat ini. Editor menerima versi server langsung dari respons simpan.
- Draft sementara tetap ditampilkan ketika localStorage tidak tersedia. ID draft dapat dibuat pada akses HTTP jaringan lokal menggunakan getRandomValues.
- Tombol coba lagi pada penilaian memuat ulang data awal. Pilihan materi dinonaktifkan selama pemuatan. Simpan semua menjelaskan bila masih ada draft yang belum tersimpan.
- Pemulihan menolak backup yang tidak memiliki seluruh tabel wajib sebelum mengganti data.
- Halaman kelas dilindungi middleware login.
- Kontrol ponsel diperbesar, ukuran teks input disesuaikan, label panjang dapat membungkus, dan keadaan tautan nonaktif diperjelas.

## Batas verifikasi

Browser otomatis tidak tersedia pada sesi ini. Tata letak, interaksi keyboard, dan tampilan ponsel belum diverifikasi secara visual. Sebelum pemakaian langsung, lakukan satu alur singkat pada browser/perangkat tujuan: login, pilih kelas/materi, simpan nilai, lihat rekap, lalu unduh laporan. Pengujian ini belum memverifikasi konfigurasi server deployment tujuan, HTTPS, atau persistensi disk di penyedia hosting.
