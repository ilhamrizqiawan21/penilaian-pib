# Stack
- TypeScript + React 19 + Next.js 15 App Router.
- npm is pinned via packageManager npm@11.16.0; Node engine 24.x.
- SQLite via better-sqlite3; validation uses Zod; icons use lucide-react; tests use Vitest.
- CSS is local/global CSS with shared tokens in app/globals.css; navigation overrides in app/navigation.css and app/sidebar-fixes.css.
- Lerd registers this as a custom container site on port 3000; current local site domain is penilaian-pib.test.
