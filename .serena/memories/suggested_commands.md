# Commands
- Install: npm ci.
- Dev: npm run dev or project launcher ./mulai-pib.sh.
- Verification: npm run typecheck, npm test -- --run, npm run build, npm run perf:check.
- Aggregate: npm run check.
- Database bootstrap only for a new database: npm run db:setup.
- For Lerd diagnostics, use site/diag/logs tools with absolute project path.
